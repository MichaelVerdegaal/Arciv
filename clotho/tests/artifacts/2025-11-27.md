## GLF-DF
I needed to fix the forecast for GLF-DF, because *something* went wrong there, and now my current champion model produces near zero forecasts.

I added a ton of debug statements in everything that the inference pipeline calls. This was my next best bet, because i really didn't see much weird in the debugger or excel sheet.

It seems the error was because a leading NaN was left in the dataset/input, causing everything to explode. 

I made the errors more clear, and also updated the trimming function to be able to handle NaN's optionally. Then the entire issue is quite clear, i just forgot to rebuild the dataset before running inference.... Though my question remains on how that could lead to a broken dataset like this, i expected this to be impossible honestly.

I added some more guardrail checks and descriptive warnings to prevent this in the future.
