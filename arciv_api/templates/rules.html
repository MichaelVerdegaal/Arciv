Rules

URL rules run top to bottom; the first match wins. skip drops a URL (the reason is shown when archiving); rewrite swaps the host for the replacement and keeps processing. File-extension, image-proxy, and IP-host skips are built in and not listed here.

Match types explained
domain

Matches a site and all its subdomains (registered domain level).

Pattern format: Just the domain, no https:// or path. Example: youtube.com matches youtube.com, m.youtube.com, www.youtube.com, etc.

Use case: Skip or rewrite an entire site and all subdomains.

Example: Skip all Medium articles: pattern medium.com, action skip.

host

Matches one exact hostname (including port if specified).

Pattern format: The hostname only, no https:// or path. Include port if needed. Examples: api.github.com or localhost:3000

Use case: Target a specific subdomain without affecting others on the same registered domain.

Example: Skip app.powerbi.com but allow learn.powerbi.com.

starts_with

Matches URLs that begin with the pattern string (path-aware).

Pattern format: Include https:// and any path prefix. Examples: https://github.com/pytorch or https://localhost:8000

Use case: Match a specific path or subdirectory, or all URLs from a local server.

Example: Skip https://localhost to exclude local development URLs.

exact

Matches the complete URL exactly (including path, query, and scheme).

Pattern format: The full URL with https://, path, and query. Example: https://example.com/page

Use case: Target one specific URL.

Example: Skip https://example.com/login but allow https://example.com/article.

regex

Matches using a regular expression (case-insensitive). Advanced pattern matching with capture group support.

Pattern format: A valid regular expression. Examples: ^https://arxiv\.org/abs/(.*)$ or example\.com/admin.*

Use case: Match complex URL patterns with path manipulation using capture groups.

Example with rewrite: Pattern ^https://arxiv\.org/abs/(.*)$, replacement https://arxiv.org/pdf/$1 transforms https://arxiv.org/abs/2606.14647 to https://arxiv.org/pdf/2606.14647. Use $1, $2, etc. to reference captured groups.

Rewrite action

Rewrite replaces the URL. Behavior depends on the match type:

  • domain/host/starts_with/exact: Replacement is treated as a hostname; the full URL host is swapped while path and query are preserved. E.g., medium.com → scribe.rip transforms https://medium.com/@user/post to https://scribe.rip/@user/post.
  • regex: Replacement is a rewrite pattern that can use $1, $2, etc. to reference captured groups. E.g., ^https://arxiv\.org/abs/(.*)$ → https://arxiv.org/pdf/$1 enables full URL transformation including path changes.
